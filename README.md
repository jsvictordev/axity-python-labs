# Axity Python Labs

Repositorio destinado al desarrollo, documentación y entrega de los laboratorios prácticos del **curso de Python de Axity**.

## Objetivo

Fortalecer los conocimientos en Python mediante ejercicios prácticos, aplicando buenas prácticas de programación, calidad de código, pruebas automatizadas, patrones de diseño y arquitectura de software.

## Contenido del curso

## Tecnologías y herramientas

Durante el desarrollo de los laboratorios se utilizarán diferentes tecnologías y herramientas, entre ellas:

- **Lenguaje:** Python 3.12
- **Gestión de dependencias:** Poetry
- **Calidad de código:** Black, isort, Ruff, mypy y pre-commit
- **Pruebas:** pytest, unittest.mock y Hypothesis
- **APIs:** FastAPI, HTTPX y Pydantic
- **Bases de datos:** SQLite, PostgreSQL, SQLAlchemy y Alembic
- **Arquitectura:** SOLID, patrones de diseño, arquitectura hexagonal y limpia
- **DevOps:** Docker, GitHub Actions y Azure
- **Ciencia de datos:** Pandas, NumPy y scikit-learn
